# Game

## 개발 실행

```sh
npm install
npm run dev
```

## 빌드

```sh
npm run build
npm run preview
```

게임 규칙 회귀는 `src/gameRules.js`의 순수 함수를 Node assertion으로 확인하고, 프로덕션 빌드는 `npm run build`로 검증합니다. 별도의 테스트 프레임워크는 아직 사용하지 않습니다.

## 구조

- `src/main.js`: Phaser 게임 초기화
- `src/MainScene.js`: 게임 화면, 입력, 전투 흐름
- `src/gameState.js`: 런타임 재화·진행·성장 상태
- `src/gameRules.js`: 상태를 입력으로 받는 순수 비용·전투·환생 계산
- `src/styles.css`: 페이지 스타일

게임 씬은 400×600 크기입니다. 하단 6개 탭은 화면 아래 한 줄에 있고, 선택한 탭의 내용은 그 위 패널에 표시합니다. 기능은 단계적으로 연결되므로 구현 전 탭에는 준비 안내가 표시됩니다.

## 확정된 진행 규칙

- 스테이지는 25라운드이며, 각 라운드는 일반 몬스터 50마리 처치 후 보스전으로 이어집니다. 25번째 라운드의 보스는 더 강하고, 처치하면 다음 스테이지로 이동합니다.
- 5번째 라운드 보스를 처치하면 환생이 해금됩니다. 이후 수동 환생이 가능하며, 해금된 상태에서 사망하면 자동 환생합니다.
- 전투 중 몬스터는 접근을 마친 뒤 1초마다 공격합니다. 플레이어 기본 최대 체력은 100이며, 일반 몬스터 피해는 `10 + (스테이지 - 1) * 2 + (라운드 - 1)`, 일반 보스는 3배, 25라운드 최종 보스는 5배입니다.
- 일반 몬스터 체력은 스테이지와 라운드에 따라 증가하며, 일반 보스는 해당 라운드 일반 몬스터의 5배, 최종 보스는 10배입니다. 정확한 밸런스는 추후 조정할 수 있습니다.
- 환생 전 사망하면 현재 스테이지의 1라운드로 돌아가고 체력을 회복합니다. 환생 가능 상태에서 사망하면 환생 처리됩니다.
- 환생 시 스테이지·라운드, 영력 강화, 경지는 초기화합니다. 업·선석·법보와 기존 영구 강화는 보존하며, 공법·체질은 초기화해 새 환생에서 다시 선택합니다.
- 라운드 보스를 처치할 때마다 업을 1 획득합니다. 현재 실행 중 환생 간 보존만 적용하며, 새로고침 후 저장은 이번 범위에 포함하지 않습니다.
- 환생 탭의 체질 하위 탭에서 환생마다 체질을 최대 하나 구매할 수 있습니다. 체질1은 5업으로 공격력 +10%, 체질2는 10업으로 최대 체력 +20%, 체질3은 25업으로 공격력과 최대 체력 +20%를 적용합니다. 선택한 체질은 다음 환생 때 초기화되며, 환생 자체의 추가 업 보상은 없습니다.
- 환생을 시작할 때 공법 세 가지 중 하나를 반드시 선택합니다. 염화공은 무료로 공격력 +10%/레벨, 금강결은 5업으로 최대 체력 +10%/레벨, 태허록은 10업으로 공격력·최대 체력 +5%/레벨을 제공합니다. 공법은 첫 50영력, 이후 1.5배 비용으로 강화하며 최대 10레벨입니다. 결단기·사축기·진선 진입 시 효과 배율이 각각 1.5배·2배·2.5배가 되도록 자동 진화합니다. 수동 환생은 선택 화면에서 취소할 수 있고, 사망 자동 환생은 선택이 끝날 때까지 대기합니다. 액티브/패시브 공법은 후속 구현 대상입니다.
- 몬스터 처치 시 일반 몬스터 0.1%, 보스 5% 확률로 법보 하나를 바로 획득합니다. 드랍 성공 시 하계·상계·선보 확률은 80%·19%·1%이며, 등급 내 아이템은 균등하게 추첨합니다. 청운검은 공격력 +5%, 수호옥은 최대 체력 +5%, 천뢰검은 공격력 +15%, 현무갑은 최대 체력 +15%, 시간륜은 치명타 확률 +5%p를 제공합니다. 보유 효과는 장착 없이 적용되고 중복 획득 효과도 누적됩니다. 법보는 환생해도 유지되며 선석 뽑기는 아직 포함하지 않습니다.
- 능력치 탭의 여섯 강화는 영력을 사용합니다. 공격력은 레벨당 +2, 체력은 레벨당 최대 체력 +20(강화 즉시 현재 체력도 +20 회복), 치명타 확률은 +1%p(최대 100%), 치명타 피해는 +10%p(최대 500%)입니다. 공격속도는 공격 간격을 레벨당 30ms 줄여 최소 100ms까지, 이동속도는 몬스터 접근 시간을 레벨당 25ms 줄여 최소 150ms까지 단축합니다.
- 체력·치명타 피해·이동속도 강화의 시작 비용/증가율은 각각 20 영력·1.2배, 50 영력·1.5배, 25 영력·1.4배입니다. 기존 공격력·치명타 확률·공격속도 강화의 비용 공식은 유지합니다.
- 능력치 강화 목록은 한 열 스크롤 방식이며, 마우스 휠과 드래그를 지원합니다.
- 경지는 라운드 보스 처치 시 자동 승급합니다. 승급 기준은 연기기부터 순서대로 2·3·4·5·7·9·12·15·19·23라운드입니다. 현재 경지의 배율을 능력치 강화와 영구 강화를 반영한 최종 공격력·최대 체력에 한 번 적용하며, 승급 시 체력을 새 최대치까지 회복합니다. 환생 전 사망으로 라운드가 초기화되어도 경지는 유지되고 환생할 때만 범인으로 초기화됩니다.

## 화면 크기와 입력

Phaser 캔버스는 400×600이며 `Phaser.Scale.FIT`과 중앙 정렬을 사용해 사용 가능한 화면에 비율을 유지하며 맞춥니다. 축소된 화면에서 게임 내부 UI 재배치 대신 캔버스 전체를 축소합니다.
