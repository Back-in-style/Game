# Game

## 개발 실행

```sh
npm install
npm run dev
```

## 빌드

```sh
npm run build
npm run preview
```

## 구조

- `src/main.js`: Phaser 게임 초기화
- `src/MainScene.js`: 게임 화면, 입력, 전투 흐름
- `src/gameState.js`: 런타임 재화·진행·성장 상태
- `src/gameRules.js`: 상태를 입력으로 받는 순수 비용·전투·환생 계산
- `src/styles.css`: 페이지 스타일

게임 씬은 400×600 크기입니다. 하단 6개 탭은 화면 아래 한 줄에 있고, 선택한 탭의 내용은 그 위 패널에 표시합니다. 기능은 단계적으로 연결되므로 구현 전 탭에는 준비 안내가 표시됩니다.

## 참고 사항 관리

작업 중 새로 확인한 실행 방법, 안정적인 구조 정보, 개발상 제약은 이 README에 반영합니다. 작업별 변경 내용과 검증 결과는 루트의 `Workflow.md`에 기록합니다. 각 작업을 마칠 때 두 문서를 모두 확인하고, 새 참고 사항을 해당 역할에 맞게 갱신합니다.

## 기능 요구사항

예정된 게임 기능과 재화·진행 규칙의 초안은 루트의 `plan.md`를 참고합니다. 기능 구현 순서와 단계별 검증 기준은 `Workflow.md`에 기록합니다.

새 기능은 `Workflow.md`의 순차 구현 계획을 따르며, 진행·재화 규칙을 확정한 뒤 상태/계산, 전투 루프, 성장 기능 순으로 연결합니다.

## 확정된 진행 규칙

- 스테이지는 25라운드이며, 각 라운드는 일반 몬스터 50마리 처치 후 보스전으로 이어집니다. 25번째 라운드의 보스는 더 강하고, 처치하면 다음 스테이지로 이동합니다.
- 5번째 라운드 보스를 처치하면 환생이 해금됩니다. 이후 수동 환생이 가능하며, 해금된 상태에서 사망하면 자동 환생합니다.
- 환생 시 스테이지·라운드, 영력 강화, 경지는 초기화합니다. 업·선석·법보와 기존 영구 강화는 보존하며, 공법·체질은 초기화해 새 환생에서 다시 선택합니다.
- 라운드 보스를 처치할 때마다 업을 1 획득합니다. 현재 실행 중 환생 간 보존만 적용하며, 새로고침 후 저장은 이번 범위에 포함하지 않습니다.
